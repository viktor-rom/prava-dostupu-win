Від тексту до даних

У програмі на C# все, що вводить користувач — це спочатку просто текст (string). Щоб компілятор зрозумів ці дані, їх потрібно розділити на частини, очистити від помилок та правильно перетворити на потрібні дані. Використовуйте цю інтерактивну панель, щоб побачити, як це працює.

Зразок програмного тексту №2

➤ В якості розділових знаків в рядку можна використовувати будь-який символ. Хай це буде пробіл. Нехай користувач помилково увів зайві пробіли (розділові знаки)
➤ В такій ситуації метод Split(' ') розділить рядок на більшу кількість частин, деякі з яких будуть порожніми. Щоб уникнути цього, можна використовувати перезавантаження методу Split і вказати опцію StringSplitOptions.RemoveEmptyEntries, яка видаляє пусті елементи з результату. 


	using System;
	class Program
	{
		static void Main()
		{
			Console.Write("Введіть ваше ім'я, вік та місто через пробіл: ");
			string input = Console.ReadLine();
			string[] parts = input.Split(new char[] {' '}, StringSplitOptions.RemoveEmptyEntries);
			string name = parts[0];
			int age = int.Parse(parts[1]);
			string city = parts[2];
			Console.WriteLine("Ім'я: {0}, Вік: {1}, Місто: {2}", name, age, city);
		}
	}

Розділення рядка: Метод Split
Метод Split розрізає один довгий рядок на масив підрядків за певним розділювачем.
➤ Класичний підхід (C# 5.0): input.Split(new char[] {';'})
➤ Тут new char[] — це створення масиву символів "на льоту". Метод очікує масив, бо ви можете захотіти розділити рядок за кількома знаками одночасно (наприклад, ; та ,).
Механізм роботи: Програма сканує рядок, знаходить розділювач, "відрізає" текст до нього і кладе у комірку масиву.
Порожні записи: Якщо користувач введе два розділювачі поспіль (;;), без додаткових налаштувань програма створить порожній рядок "". Щоб цього уникнути, використовують прапорець StringSplitOptions.RemoveEmptyEntries.

Треба зауважити, що new — це оператор створення об'єкта

Коли ми пишемо new char[], ми даємо три чіткі команди:
	1. Замовлення пам'яті: "Система, мені потрібна ділянка пам'яті для зберігання символів".
	2. Визначення типу: "Це буде не просто текст, а саме масив символів (char[])".
	3. Ініціалізація: За допомогою дужок { ' ' } вказуємо, що туди вкладеться ось цей пробіл".

	using System;
	class Program
	{
		static void Main()
		{
			Console.Write("Введіть ваше ім'я, вік та місто через ';': ");

			string[] parts = input.Split(';');
			if (parts.Length != 3)

				Console.WriteLine("Помилка: Введіть дані у форматі 'Ім'я;Вік;Місто'");
				return;
			}
			string name = parts[0].Trim();
			int vik;
			try
			{
				vik = int.Parse(parts[1].Trim());
			}
				catch (FormatException)
			{
				Console.WriteLine("Помилка: Неправильний формат віку. Будь ласка, введіть число.");
				return;
			}
			string city = parts[2].Trim();
			Console.WriteLine("Ім'я: {0}, Вік: {1}, Місто: {2}", name, age, city);
		}
	}

Механізм Try-Catch

Якщо в тексті програми використовується int.Parse, тоді потрібно використовувати перехоплювачі можливих помилок. Вони потрібні для тих випадків, коли не відомо як відпрацює програма і де можливі помилки. Це захист від "падіння" програми. Натисніть на кнопку симуляції, щоб побачити, як програма перестрибує помилки.

try {
// Спроба перетворити
int vik = int.Parse(input);
// Успіх
Console.WriteLine(vik);
} catch (FormatException) {
// Рятувальна сітка
Console.WriteLine("Помилка!");
}
