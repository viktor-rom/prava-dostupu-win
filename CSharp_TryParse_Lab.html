Шпаргалка: Безпечне перетворення

TryParse Множинна перевірка Do-While Цикл

Мистецтво безпечного коду

У мові C# перетворення рядка на число є операцією з високим ризиком. Ця інтерактивна лабораторія демонструє, чому int.TryParse є стандартом для створення відмовостійких програм, та як ефективно перевіряти складні набори даних.

1

Базова конструкція TryParse

Метод int.Parse ініціює критичну помилку (виняток) при некоректних даних, що зупиняє програму. Натомість TryParse повертає булеве значення (true/false), дозволяючи програмі продовжити роботу. Спробуйте ввести некоректні дані (наприклад, текст) нижче, щоб побачити різницю.

// Очікування виконання команди...

Статус програми

2

Множинна перевірка (Логічне "І")

При отриманні набору параметрів (наприклад, 5 значень з одного рядка) використання вкладених if є неефективним. Найкращий спосіб — використати оператор && (І). Завдяки "короткому замиканню" (short-circuit evaluation), C# зупинить перевірку на першому ж помилковому значенні.

Абстрактний шаблон

Для масивів довільної довжини N.

if (items.Length >= N) { bool isAllOk = TryParse(items[0], out v1) && TryParse(items[1], out v2) && ... TryParse(items[N-1], out vN); if (isAllOk) { /* Success */ } }

💡 Чому це краще?

  • Стабільність: Ніяких винятків.
  • Чистота: Немає "піраміди" з if/else.
  • Продуктивність: Перевірка зупиняється миттєво при першій помилці.
3

Циклічна валідація (do-while)

Щоб змусити користувача вводити дані до тих пір, поки вони не стануть коректними, використовується цикл do-while. Це гарантує, що програма не продовжить виконання з "битими" даними.
